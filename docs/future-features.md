# Future Features & Deferred Items

This document tracks features and enhancements that are planned for future implementation but not part of the initial release.

## Deferred Features

### AI & Strategy
- **Advanced AI Strategies**
  - Defensive play analysis (safe tile detection)
  - Offensive optimization beyond basic shanten
  - Risk assessment for discards
  - Expected value calculations for complex scenarios
  - Machine learning-based move predictions

### Multiplayer & Game Modes
- **Multiplayer Support**
  - Full 4-player game simulation
  - Real-time multiplayer game hosting
  - Spectator mode
  - Tournament mode

### User Management
- **User Accounts**
  - User registration and authentication
  - Personal game history per user
  - User preferences and settings
  - Saved game states

### Analytics & Statistics
- **Analytics Dashboard**
  - Win rate tracking
  - Common mistake analysis
  - Performance metrics over time
  - Tile efficiency statistics
  - Yaku frequency analysis

### Additional Mahjong Variants
- Hong Kong Old Style
- American Mahjong
- Chinese Classical
- Other regional variants

### Advanced Features
- **Mobile App Integration**
  - Native iOS/Android apps
  - Push notifications for game events
  
- **Replay Analysis**
  - Import game logs from other platforms
  - Step-by-step replay with AI commentary
  - Alternative move suggestions at each decision point
  
- **Educational Mode**
  - Tutorial system for beginners
  - Detailed explanations for suggested moves
  - Interactive lessons on Mahjong strategy
  - Yaku reference guide

- **Integration with Online Platforms**
  - Connect to Tenhou, Mahjong Soul, etc.
  - Import game data for analysis
  - Export analyzed games

### Performance & Scalability
- **Advanced Rate Limiting**
  - Per-user quotas
  - Premium tier with higher limits
  - Adaptive rate limiting based on server load

- **Caching & Optimization**
  - Redis cache for common game states
  - Pre-computed move suggestions for standard scenarios
  - Database query optimization

### UI/UX Enhancements
- **Visualization Improvements**
  - 3D tile rendering option
  - Customizable tile sets and themes
  - Animation effects for tile movements
  - Sound effects
  - Accessibility features (screen reader support, high contrast mode)

## Notes
- Features will be prioritized based on user feedback and FF14 plugin requirements
- Performance benchmarks should be established before adding complex features
- Maintain backward compatibility with FF14 plugin API as features are added
