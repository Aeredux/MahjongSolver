Mahjong Server API Guide

Base URL: http://localhost:8080

This server provides Japanese Riichi Mahjong move suggestions and call-decision evaluation. All requests and responses use JSON. All tile types are passed as strings (see Tile Reference below).

Hand Size Convention

Always send 13 tiles in the hand array. The drawn/called tile is always provided as a separate field:

  • suggest-move: hand (13 tiles) + optional drawn_tile
  • evaluate-call: hand (13 tiles) + called_tile
  • validate-move: hand (13 tiles) + optional drawn_tile

The server automatically adds the drawn/called tile to the hand internally when needed (e.g., for TSUMO and closed KAN evaluations).

POST /api/suggest-move

Given a player's current hand (13 or 14 tiles), returns a ranked list of discard suggestions with shanten values, ukeire counts, confidence scores, and reasoning.

Request Body

{
  "hand": ["<TileType>", ...],
  "drawn_tile": "<TileType> or null"
}
FieldTypeRequiredDescription
handarray of TileType stringsYesAlways 13 tiles in your closed hand. The drawn tile (if any) is provided separately via drawn_tile.
drawn_tileTileType string or nullNoThe tile just drawn. Can be null. The suggestion engine evaluates all tiles in hand.
opponentsarray or nullNoPer-opponent discard information. Enables discard-aware ukeire, defense ranking (genbutsu / suji / kabe / one-chance), and tsumogiri tenpai danger. See below.
discard_tilesarray or nullNoCaller's own pond (used for visible-tile ukeire). If omitted, player.discards is used when present.
doraarray or nullNoDoman dora panel tiles as displayed — the panel tile is the dora (no Tenhou +1 remap). Counted as visible and kept on ranking ties.
meldsarray or nullNoCaller's own open melds {type, tiles[]}. Used for open-hand shanten and visible counts.
playerobject or nullNoOptional same shape as an opponents[] entry. player.melds / player.discards are used when top-level melds / discard_tiles are empty. Nested player.riichi is not consumed.
seat_windstringNoPlayer's seat wind. Used for yakuhai keep-value and call policy.
round_windstringNoCurrent round wind. Used for yakuhai keep-value and call policy.

opponents[] Fields

FieldTypeDescription
windstringOpponent's seat wind. One of: EAST, SOUTH, WEST, NORTH
discardsarray of DiscardedTileAll tiles this opponent has discarded, in order.
riichibooleanWhether this opponent is in riichi. Raises defense threat weight; genbutsu applies to every pond.

DiscardedTile Fields

FieldTypeDescription
tileTileType stringThe tile that was discarded.
tsumogiribooleanWhether the tile was drawn and immediately discarded (top-deck discard). Consecutive tsumogiri discards indicate tenpai danger.

Response Body

{
  "current_shanten": 0,
  "suggestions": [
    {
      "discard_tile": "WHITE",
      "shanten_after_discard": 0,
      "confidence": 1.0,
      "reasoning": "Discarding WHITE keeps you at tenpai (0-shanten). 8 tiles can improve your hand.",
      "ukeire_count": 8
    },
    {
      "discard_tile": "S1",
      "shanten_after_discard": 1,
      "confidence": 0.5,
      "reasoning": "Discarding S1 worsens shanten from 0 to 1.",
      "ukeire_count": 24
    }
  ]
}
FieldTypeDescription
current_shantenintShanten of the current hand. -1 = complete, 0 = tenpai, 1 = 1-shanten, etc.
suggestionsarrayAll possible discards, sorted best-first.
suggestions[].discard_tileTileType stringThe tile to discard.
suggestions[].shanten_after_discardintShanten after discarding this tile.
suggestions[].confidencefloat 0.0–1.01.0 = best possible discard; 0.5 = suboptimal; 0.0 = worsens shanten.
suggestions[].reasoningstringHuman-readable explanation.
suggestions[].ukeire_countintNumber of tiles remaining in the wall that would improve the hand after this discard.

Example — basic (no opponent data)

{
  "hand": ["S1","S2","S3","S4","S5","S6","S7","S8","S9","M2","M3","WHITE","WHITE","WHITE"],
  "drawn_tile": null
}

Example — with opponent discards (discard-aware ukeire + genbutsu)

{
  "hand": ["M1","M2","M3","M4","M5","M6","P1","P2","P3","S7","S8","S9","EAST"],
  "drawn_tile": null,
  "opponents": [
    {
      "wind": "EAST",
      "riichi": true,
      "discards": [
        {"tile": "M9", "tsumogiri": false},
        {"tile": "NORTH", "tsumogiri": false},
        {"tile": "S1", "tsumogiri": true},
        {"tile": "S2", "tsumogiri": true}
      ]
    },
    {
      "wind": "SOUTH",
      "riichi": false,
      "discards": [
        {"tile": "EAST", "tsumogiri": false},
        {"tile": "M1", "tsumogiri": true},
        {"tile": "P9", "tsumogiri": true},
        {"tile": "P8", "tsumogiri": true},
        {"tile": "P7", "tsumogiri": true}
      ]
    }
  ]
}

With opponent data, reasoning in each suggestion will include:

  • Accurate ukeire based on visible discards (e.g. "Ukeire: 6 tiles (5.3% of remaining wall)")
  • Genbutsu flags (e.g. "Genbutsu safe vs EAST (riichi)")
  • Tenpai danger warnings (e.g. "Caution: SOUTH (high tenpai danger: 4 tsumogiri)")
  • Scarcity warnings (e.g. "Only 1 copy of M1 left in wall")

POST /api/evaluate-call

Evaluates whether the player should make a call (pon, chi, kan, ron, riichi, tsumo).

Request Body

{
  "hand": ["<TileType>", ...],
  "called_tile": "<TileType>",
  "call_type": "<CallType>",
  "sequence_tiles": ["<TileType>", "<TileType>"],
  "menzen": true,
  "player_score": 25000,
  "open_kan": false,
  "opponents": [],
  "seat_wind": "EAST",
  "round_wind": "EAST"
}
FieldTypeRequiredDescription
handarray of TileType stringsYesAlways 13 tiles in your closed hand. The called tile is provided separately via called_tile.
called_tileTileType stringYesThe tile being considered for the call.
call_typestringYesOne of: CHI, PON, KAN, RON, RIICHI, TSUMO
sequence_tilesarray of 2 TileType stringsCHI onlyThe two tiles in hand that form a sequence with called_tile. E.g. calling chi on M3 with M1M2 in hand: ["M1","M2"].
menzenbooleanNoWhether the hand is currently closed. Default: true.
player_scoreintNoPlayer's current score. Used for riichi validation (needs ≥1000). Default: 25000.
open_kanbooleanNoWhether the kan would be open. Default: false.
opponentsarray or nullNoPer-opponent discard information (same format as suggest-move).
seat_windstringNoPlayer's seat wind. One of: EAST, SOUTH, WEST, NORTH
round_windstringNoCurrent round wind. One of: EAST, SOUTH, WEST, NORTH
doraarray or nullNoDoman dora panel (tile as displayed). Used like yakuhai when deciding pon/chi/kan.
meldsarray or nullNoCaller's own open melds, for open-hand shanten / winning checks.
playerobject or nullNoOptional same shape as an opponents[] entry; player.melds fills in when top-level melds is empty.

CallType Values

ValueDescription
RONWin by claiming another player's discard
TSUMOWin by self-draw
RIICHIDeclare riichi (closed tenpai hand)
PONCall a tile to form a triplet
CHICall a tile to form a sequence (left player only)
KANCall or declare a quad

  "call_type": "PON",
  "should_call": true,
  "confidence": 0.8,
  "reasoning": "Pon improves hand efficiency. Shanten goes from 2 to 1.",
  "shanten_before": 2,
  "shanten_after": 1
}
FieldTypeDescription
call_typestringEchoes back the call type.
should_callbooleantrue = recommended to make the call.
confidencefloat 0.0–1.0Confidence in the recommendation.
reasoningstringExplanation.
shanten_beforeintShanten before the call.
shanten_afterintShanten after the call (if made).

  "called_tile": "EAST",
  "call_type": "RON",
  "menzen": true,
  "player_score": 25000
}

{
  "hand": ["M3","M4","P1","P2","P3","S1","S2","S3","S7","S8","S9","EAST","EAST"],
  "called_tile": "M2",
  "call_type": "CHI",
  "sequence_tiles": ["M3","M4"],
  "menzen": true,
  "player_score": 25000

POST /api/validate-move

Checks whether discarding a specific tile from the given hand is legal.

Request Body

{
  "hand": ["<TileType>", ...],
  "discard_tile": "<TileType>",
  "drawn_tile": "<TileType> or null",
  "riichi": false
}
FieldTypeRequiredDescription
handarray of TileTypeYesAlways 13 tiles in your closed hand. The drawn tile (if any) is provided separately via drawn_tile.
discard_tileTileType stringYesThe tile the player wants to discard.
drawn_tileTileType string or nullNoThe tile just drawn. Required to validate riichi tsumogiri rule.
riichibooleanNoWhether the player is in riichi. If true, only the drawn tile may be discarded.

Response Body

{
  "valid": true,
  "errors": []
}

If invalid: "valid": false with a list of error messages explaining why.

Shanten Values

ValueMeaning
-1Complete hand (winning)
0Tenpai — one tile away from winning
11-shanten — one useful draw+discard away from tenpai
NN exchanges away from tenpai

Confidence Score

ValueMeaning
1.0Best discard — achieves the lowest possible shanten
0.5Maintains shanten (not optimal but not harmful)
0.0Worsens shanten

Integration Notes

  • All tile type strings are case-sensitive — use uppercase (M1, not m1).
  • Always send 13 tiles in hand. The drawn tile is sent separately via drawn_tile.
  • drawn_tile is informational — include it in hand if you want it evaluated as a discard candidate.
  • suggestions is always sorted best-first. Use suggestions[0] for the single best recommended discard.
