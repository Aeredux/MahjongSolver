Mahjong Server API Guide

Base URL: http://localhost:8080

This server provides Japanese Riichi Mahjong move suggestions and call-decision evaluation. All requests and responses use JSON. All tile types are passed as strings (see Tile Reference below).

POST /api/suggest-move

Given a player's current hand (13 or 14 tiles), returns a ranked list of discard suggestions with shanten values, ukeire counts, confidence scores, and reasoning.

Request Body

{
  "hand": ["<TileType>", ...],
  "drawnTile": "<TileType> or null"
}
FieldTypeRequiredDescription
handarray of TileType stringsYes13 or 14 tiles in the player's hand. If 14 tiles and drawnTile is set, the drawn tile should be included in hand.
drawnTileTileType string or nullNoThe tile just drawn. Can be null. The suggestion engine evaluates all tiles in hand.
opponentsarray or nullNoPer-opponent discard information. Enables discard-aware ukeire, genbutsu detection, and tsumogiri tenpai danger. See below.

opponents[] Fields

FieldTypeDescription
windstringOpponent's seat wind. One of: EAST, SOUTH, WEST, NORTH
discardsarray of DiscardedTileAll tiles this opponent has discarded, in order.
riichibooleanWhether this opponent is in riichi. Enables genbutsu detection.

DiscardedTile Fields

FieldTypeDescription
tileTileType stringThe tile that was discarded.
tsumogiribooleanWhether the tile was drawn and immediately discarded (top-deck discard). Consecutive tsumogiri discards indicate tenpai danger.

Response Body

{
  "currentShanten": 0,
  "suggestions": [
    {
      "discardTile": "WHITE",
      "shantenAfterDiscard": 0,
      "confidence": 1.0,
      "reasoning": "Discarding WHITE keeps you at tenpai (0-shanten). 8 tiles can improve your hand.",
      "ukeireCount": 8
    },
    {
      "discardTile": "S1",
      "shantenAfterDiscard": 1,
      "confidence": 0.5,
      "reasoning": "Discarding S1 worsens shanten from 0 to 1.",
      "ukeireCount": 24
    }
  ]
}
FieldTypeDescription
currentShantenintShanten of the current hand. -1 = complete, 0 = tenpai, 1 = 1-shanten, etc.
suggestionsarrayAll possible discards, sorted best-first.
suggestions[].discardTileTileType stringThe tile to discard.
suggestions[].shantenAfterDiscardintShanten after discarding this tile.
suggestions[].confidencefloat 0.0–1.01.0 = best possible discard; 0.5 = suboptimal; 0.0 = worsens shanten.
suggestions[].reasoningstringHuman-readable explanation.
suggestions[].ukeireCountintNumber of tiles remaining in the wall that would improve the hand after this discard.

Example — basic (no opponent data)

{
  "hand": ["S1","S2","S3","S4","S5","S6","S7","S8","S9","M2","M3","WHITE","WHITE","WHITE"],
  "drawnTile": null
}

Example — with opponent discards (discard-aware ukeire + genbutsu)

{
  "hand": ["M1","M2","M3","M4","M5","M6","P1","P2","P3","S7","S8","S9","EAST"],
  "drawnTile": null,
  "opponents": [
    {
      "wind": "EAST",
      "riichi": true,
      "discards": [
        {"tile": "M9", "tsumogiri": false},
        {"tile": "NORTH", "tsumogiri": false},
        {"tile": "S1", "tsumogiri": true},
        {"tile": "S2", "tsumogiri": true}
      ]
    },
    {
      "wind": "SOUTH",
      "riichi": false,
      "discards": [
        {"tile": "EAST", "tsumogiri": false},
        {"tile": "M1", "tsumogiri": true},
        {"tile": "P9", "tsumogiri": true},
        {"tile": "P8", "tsumogiri": true},
        {"tile": "P7", "tsumogiri": true}
      ]
    }
  ]
}

With opponent data, reasoning in each suggestion will include:

  • Accurate ukeire based on visible discards (e.g. "Ukeire: 6 tiles (5.3% of remaining wall)")
  • Genbutsu flags (e.g. "Genbutsu safe vs EAST (riichi)")
  • Tenpai danger warnings (e.g. "Caution: SOUTH (high tenpai danger: 4 tsumogiri)")
  • Scarcity warnings (e.g. "Only 1 copy of M1 left in wall")

POST /api/evaluate-call

Evaluates whether the player should make a call (pon, chi, kan, ron, riichi, tsumo).

Request Body

{
  "hand": ["<TileType>", ...],
  "calledTile": "<TileType>",
  "callType": "<CallType>",
  "sequenceTiles": ["<TileType>", "<TileType>"],
  "isMenzen": true,
  "playerScore": 25000,
  "isOpenKan": false
}
FieldTypeRequiredDescription
handarray of TileType stringsYesCurrent tiles in hand (not including the called tile).
calledTileTileType stringYesThe tile being considered for the call.
callTypestringYesOne of: CHI, PON, KAN, RON, RIICHI, TSUMO
sequenceTilesarray of 2 TileType stringsCHI onlyThe two tiles in hand that form a sequence with calledTile. E.g. calling chi on M3 with M1M2 in hand: ["M1","M2"].
isMenzenbooleanNoWhether the hand is currently closed. Default: true.
playerScoreintNoPlayer's current score. Used for riichi validation (needs ≥1000). Default: 25000.
isOpenKanbooleanNoWhether the kan would be open. Default: false.

CallType Values

ValueDescription
RONWin by claiming another player's discard
TSUMOWin by self-draw
RIICHIDeclare riichi (closed tenpai hand)
PONCall a tile to form a triplet
CHICall a tile to form a sequence (left player only)
KANCall or declare a quad

Response Body

{
  "callType": "PON",
  "shouldCall": true,
  "confidence": 0.8,
  "reasoning": "Pon improves hand efficiency. Shanten goes from 2 to 1.",
  "shantenBefore": 2,
  "shantenAfter": 1
}
FieldTypeDescription
callTypestringEchoes back the call type.
shouldCallbooleantrue = recommended to make the call.
confidencefloat 0.0–1.0Confidence in the recommendation.
reasoningstringExplanation.
shantenBeforeintShanten before the call.
shantenAfterintShanten after the call (if made).

Example — evaluate ron

{
  "hand": ["M1","M2","M3","M4","M5","M6","P1","P2","P3","S7","S8","S9","EAST"],
  "calledTile": "EAST",
  "callType": "RON",
  "isMenzen": true,
  "playerScore": 25000
}

Example — evaluate chi

{
  "hand": ["M3","M4","P1","P2","P3","S1","S2","S3","S7","S8","S9","EAST","EAST"],
  "calledTile": "M2",
  "callType": "CHI",
  "sequenceTiles": ["M3","M4"],
  "isMenzen": true,
  "playerScore": 25000
}

POST /api/validate-move

Checks whether discarding a specific tile from the given hand is legal.

Request Body

{
  "hand": ["<TileType>", ...],
  "discardTile": "<TileType>",
  "drawnTile": "<TileType> or null",
  "riichi": false
}
FieldTypeRequiredDescription
handarray of TileTypeYesThe player's current hand (13 or 14 tiles).
discardTileTileType stringYesThe tile the player wants to discard.
drawnTileTileType string or nullNoThe tile just drawn. Required to validate riichi tsumogiri rule.
riichibooleanNoWhether the player is in riichi. If true, only the drawn tile may be discarded.

Response Body

{
  "valid": true,
  "errors": []
}

If invalid: "valid": false with a list of error messages explaining why.

Shanten Values

ValueMeaning
-1Complete hand (winning)
0Tenpai — one tile away from winning
11-shanten — one useful draw+discard away from tenpai
NN exchanges away from tenpai

Confidence Score

ValueMeaning
1.0Best discard — achieves the lowest possible shanten
0.5Maintains shanten (not optimal but not harmful)
0.0Worsens shanten

Integration Notes

  • All tile type strings are case-sensitive — use uppercase (M1, not m1).
  • A 14-tile hand is typical after drawing; the API evaluates which tile to discard.
  • A 13-tile hand is also accepted for pre-draw analysis.
  • drawnTile is informational — include it in hand if you want it evaluated as a discard candidate.
  • suggestions is always sorted best-first. Use suggestions[0] for the single best recommended discard.
